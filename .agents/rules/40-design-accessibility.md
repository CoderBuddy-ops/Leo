# Design & Accessibility Rules

1. **Original Character Only:**
   - Leo's character is original and procedural. Never import Coucou's Mochi or HeyNixi artwork.

2. **Accessibility Standards:**
   - Full keyboard navigation (`Esc` closes, `Ctrl+Alt+Space` opens chat).
   - Support `prefers-reduced-motion` by halting continuous oscillation.
   - States must never be conveyed by color alone.

3. **Performance Budget:**
   - 60 FPS when active, 0 FPS when idle/sleepy.
