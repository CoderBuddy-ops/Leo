# Documentation Rules

1. **Keep Documentation Truthful:**
   - Clearly distinguish `Observed`, `Documented`, `Inferred`, and `Unknown / Needs test`.
   - Never claim an app works end-to-end if only unit tests ran.

2. **Update on Change:**
   - Update `TASKS.md` and `CHANGELOG.md` concurrently with feature changes.
   - Maintain working GitHub-style links in `docs/INDEX.md`.
