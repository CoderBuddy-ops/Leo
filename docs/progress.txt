- **User-Reported Failures (this session)**:
  1. Chat section not working — connected a Gemini API key but gets no AI response.
  2. Voice section not working.
  3. Cute face animation missing — user wants the animation like the app icon.
  4. Settings section/tabs on top not working.
- **Root-Cause Diagnosis**:
  - (1) Chat: the dedicated Settings window and the main dock window are **separate JS contexts with separate `AIProviderManager` instances**. The dock reads provider+key from localStorage only at page load. Changing provider/key in Settings writes localStorage but never updates the dock's in-memory manager → chat still targets the default `ollama` loopback (127.0.0.1:11434) which isn't running → "no response."
  - (2) Voice: `toggleDictation()` in `app/src/main.ts` is **fully mocked** (`Math.random()` energy, sample hardcoded transcript). No real microphone/`getUserMedia` path.
  - (3) Animation: face canvas renders but is subtle/small (60×48 CSS); not the lively blink/breathing/gaze the user expects from the icon.
  - (4) Settings tabs: nav-tab click handlers exist but the window doesn't reliably resize/show drawers (IPC `set_window_size` + CSS width), so sections appear dead.
- **Fix plan**: (a) sync provider state across windows via `storage` event + re-read on focus; (b) wire real mic input via `getUserMedia`+VAD with graceful fallback; (c) enlarge/animate the face (blink, breathing, gaze, happy squash) to match icon charm; (d) make tab switching robustly resize the native window and show drawers.
- **Next**: Implement fixes, rebuild, re-test, verify visually.
